## About ailia Document Loader

ailia Document Loader is a library for reading and writing PDF documents. It extracts text and graphics with layout information, removes text, embeds TrueType fonts and decrypts encrypted documents.

## Usage

Add the package to `pubspec.yaml` as a git dependency.

```yaml
dependencies:
  ailia_document_loader:
    git:
      url: https://github.com/ailia-ai/ailia-document-loader-flutter.git
      ref: v1.2.0
```

`ailiaDocumentLoaderFFI` is the low level binding generated by ffigen. `openAiliaDocumentLoaderLibrary()`
opens the native library bundled with the application.

```dart
import 'package:ailia_document_loader/ailia_document_loader.dart';
import 'package:ailia_document_loader/ailia_document_loader_library.dart';

final ailiaDocumentLoaderFFI ffi = ailiaDocumentLoaderFFI(openAiliaDocumentLoaderLibrary());
```

## Native libraries

| Platform | File |
|----------|------|
| macOS | `macos/libailia_document_loader.dylib` (universal) |
| iOS | `ios/libailia_document_loader.a` |
| Windows | `windows/x64/ailia_document_loader.dll`, `windows/arm64/ailia_document_loader.dll` |
| Linux | `linux/x64/libailia_document_loader.so` |
| Android | `android/src/main/jniLibs/arm64-v8a/libailia_document_loader.so` |

## macOS Download Attribute

If a security error occurs with a downloaded file on macOS, please execute the following command to remove the download attribute.

```
xattr -d com.apple.quarantine macos/libailia_document_loader.dylib
```
